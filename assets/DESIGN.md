# 晨光与夜林 · 静态卡片

四张独立卡片展示身份、研究实践、技术能力与 MiniCamp。全部使用自包含 SVG，无动画、内嵌位图、外部字体、脚本或图像滤镜。常规宽屏四张合计约 37 KB，替代原有约 9 MB 的循环动图。

浅色主题对应晨光、鼠尾草绿与暖白；深色主题对应夜林、月光与象牙色。两套图片保持相同构图、字体层次、圆角与入口。主题与昼夜的对应仅用于 GitHub Profile；个人主页仍按原有滚动路径推进昼夜。

窄屏使用独立单列构图，正文使用较大字号；研究卡与两个作品卡设有清晰动作文字和箭头。完整文字保留于可展开的「文字介绍」中，便于选择、复制与辅助阅读。

维护内容：编辑仓库根目录的 profile.json，再运行 python tools/build_cards.py。SVG、README 同步生成，不必手动编辑图片。文案与个人主页 profile.js 保持事实和术语一致。

植物图形由本项目独立绘制为简化矢量图，与个人主页共享林地、山丘、自然配色及衬线标题的视觉语言。未使用参考网站素材。
