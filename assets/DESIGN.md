# 晨光与夜林 · 简要 Profile

两张静态卡片保留简要身份、研究兴趣和爱好，首卡用醒目的“进入个人主页”作为主要入口。详细课程、项目与实践内容放在个人主页。文字使用马善政书法与 Fraunces 斜体，构建时转换为字形路径；桌面浅色两卡合计约 156 KB，无动画、脚本、滤镜、外部字体和位图请求。

浅色呈现晨光、深色呈现夜林；手机使用独立大字号构图。两端共享林地、山丘、暖白与衬线标题的视觉语言。个人主页继续按滚动推进昼夜。

编辑 profile.json，先运行 python -m pip install -r tools/requirements.txt，再运行 python tools/build_cards.py，生成八个主题与尺寸变体及 README。可访问的替代文本保留相同基本信息，首卡链接到 https://lhc-prog.github.io/ 。

首卡入口采用暖白椭圆按钮。中文与英文都转为静态矢量轮廓，跨平台不会退回系统字体。字体构建源与 OFL 许可证保留在 tools/fonts/；图片保留完整替代文本。
