# Profile 视觉素材

原创 SVG 素材采用冷白、石墨蓝和雾蓝，与个人主页保持一致。横幅和活动卡各有浅深与移动版，技术标签为独立素材，窄屏可自然换行。内容正文保留在 README 中，图片不承担唯一的信息表达。

设计参考：

- [Rauno Freiberg](https://rauno.me/)：清晰的姓名主视觉与几何构图。
- [Paco Coursey](https://paco.me/)：克制的排版与内容层级。
- [Emil Kowalski](https://emilkowal.ski/)：个人身份与作品入口的组织。
- [GitHub 官方排版指南](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github)：使用 picture 提供主题适配图片。

未复制第三方图片或组件；不包含脚本、远程字体、统计服务及星芒标志。
